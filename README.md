## Project Name
Trish's Treats

## Project Description
Trish's Treats is a multi-page, responsive website for a cupcake bakery in Alexandria, Ontario. The site introduces the bakery, showcases its cupcake menu, tells the story behind the business, and gives visitors a way to get in touch. It was built as a school project using hand-written HTML and CSS, with a small amount of JavaScript to control the mobile navigation menu.

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Clone or download this repository.
2. Keep the folder structure intact: the HTML files and `style.css` sit in the root folder, and all images go in an `images/` folder.
3. Open `index.html` in any modern web browser.

No installation, build step, or server is required.

## Features
- Home page with a welcome message and three featured cupcakes
- Cupcakes menu page with nine cupcakes displayed in a responsive CSS grid that adjusts the number of columns to the screen width without media queries
- About page telling the story of the bakery
- Contact form with name, email, and message fields (front end only; there is no backend to receive submissions yet)
- Responsive navigation bar that switches to a slide-out sidebar menu on small screens
- Blurred background image of Island Park with a colour overlay, and hover/click feedback on buttons and links
